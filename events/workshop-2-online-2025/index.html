Training workshop

Workshop 2: Numerical models for hydraulic simulation, urban flows and GPU programming

March 6–19, 2025 Online

An online, ten-day training program (6 ECTS, 60 hours) with daily lectures and hands-on sessions. The first block reviewed 1D and 2D shallow-water models, mesh generation and erodible-bed sediment transport. A block on urban flows covered high-order schemes and porosity models for urban flooding, ending with presentations of the fellows' results. A final block on GPU programming went from architectures and memory models to CUDA, Kokkos, SYCL and OpenMP, CPU-to-GPU migration and multi-GPU computing. A transferable-skills day dealt with academic integrity, publishing strategy and visibility. Each hands-on task was assessed by a report.

Lecturers & speakers

  • Pilar García-Navarro

    University of Zaragoza (GHC)

    1D hydraulic models and numerical techniques; steady and unsteady flow simulation

  • Pilar Brufau

    University of Zaragoza

    1D hydraulic models and numerical techniques (with P. García-Navarro)

  • Javier Fernández-Pato

    2D hydraulic models, numerical techniques and mesh generation

  • Sergio Martínez

    2D models for erodible beds and sediment transport; introduction to GPU programming and memory models; CPU-to-GPU migration, debugging and best practices

  • Maria Kazolea

    Inria (Bordeaux)

    Urban flows: high-order schemes for the shallow-water equations, porosity models, advanced schemes and the 2D code SLOWS

  • Reinaldo García

    Industrial applications of GPU codes

  • Mario Morales

    University of Zaragoza

    GPU performance optimization; programming models (CUDA, Kokkos, SYCL, OpenMP); multi-GPU programming

Programme

Thursday · March 6, 2025

  • 09:00–12:00 Review of one-dimensional hydraulic models and numerical techniques; steady and unsteady flow examples — Pilar García-Navarro, Pilar Brufau
  • 14:00–17:00 Hands-on: 1D unsteady flow simulation (modify, compile and run a 1D shallow-water code; report on a 1D dam-break) — Pilar García-Navarro, Pilar Brufau

Friday · March 7, 2025

  • 09:00–12:00 Review of two-dimensional hydraulic models, numerical techniques and mesh generation — Javier Fernández-Pato
  • 14:00–17:00 Hands-on: 2D unsteady flow simulation (report on a 2D dam-break) — Javier Fernández-Pato

Monday · March 10, 2025

  • 09:00–12:00 Two-dimensional models and numerical techniques for erodible beds and sediment transport — Sergio Martínez
  • 14:00–17:00 Hands-on: unsteady erosive 1D simulation (report on a 1D erosive dam-break) — Sergio Martínez

Tuesday · March 11, 2025

  • 09:15–15:00 Transferable skills: academic integrity in searching, reading and citing; publishing strategy and visibility (UiB PhD seminar, registration by Feb 15) — Various speakers, organized by UiB
  • 19:00 How to make a YouTube video (to be confirmed)

Wednesday · March 12, 2025

  • 09:00–12:00 Introduction to the shallow-water equations, focusing on higher-order numerical schemes — Maria Kazolea
  • 14:00–17:00 Hands-on: develop a higher-order 1D shallow-water code — Maria Kazolea

Thursday · March 13, 2025

  • 09:00–12:00 Porosity models: a review — Maria Kazolea
  • 14:00–17:00 Hands-on: a simple shallow-water code with porosity for urban flooding — Maria Kazolea

Friday · March 14, 2025

  • 09:00–12:00 Advanced numerical schemes; exploring the 2D code SLOWS — Maria Kazolea
  • 14:00–17:00 Presentations of the three days’ results (assessed)

Monday · March 17, 2025

  • 09:00–12:00 Introduction to GPU programming and architectures; memory models and management — Sergio Martínez
  • 14:00–17:00 Industrial application of GPU codes — Reinaldo García

Tuesday · March 18, 2025

  • 09:00–12:00 Performance optimization strategies: vectorization, load balancing, profiling — Mario Morales
  • 14:00–17:00 Programming models and abstractions: CUDA, Kokkos, SYCL, OpenMP; execution and memory spaces (task: CPU-to-GPU migration of a 2D shallow-water code) — Mario Morales

Wednesday · March 19, 2025

  • 09:00–12:00 Migration strategies from CPU to GPU; debugging; best practices for scientific computing on GPUs — Sergio Martínez
  • 14:00–17:00 Advanced topics in GPU programming: multi-GPU programming — Mario Morales
